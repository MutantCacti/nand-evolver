# Architecture

A simple summary of the planned nand-evolver data and responsibility structure.

## Loop Trees

Identify the series of nested loops that encapsulate stages of program execution.

`*` = Loops over many
`(` = Executor that varies state
`#` = State varied

### Training Loop Tree

```
Study (Driver)                                          # Source
└─* Experiment (Encoder)                                # Config, Dataset
    └─* Run (Runner)                                    # Rng
        └─* Generation (Selector, Mutator)              # Genome, Arena
            └─* Individual (Trainer)                    # Genome, Arena
                └─* Example (Verifier, Decoder)         # Arena
                    └─* Round                           # Arena
                        └─* Tick                        # Arena
                            └─* Instruction (Kernel)    # Arena
```

### Inference Loop Tree

```
Study (Driver)                                          # Source
└─* Experiment (Encoder)                                # Config, Dataset
    └─* Run (Runner)
        └─* Individual (Inferrer)                       # Arena
            └─* Example (Decoder)                       # Arena
                └─* Round                               # Arena
                    └─* Tick                            # Arena
                        └─* Instruction (Kernel)        # Arena
```
