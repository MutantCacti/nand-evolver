# Architecture

A simple summary of the planned nand-evolver data and responsibility structure.

## Loop Tree

`*` = Loops over many

```
Experiment (Encoder)
└─* Run (Dataset, Rng)
    └─* Generation (Selector, Mutator)
        └─* Individual (Genome, Trainer)
            └─* Examples (Verifier)
                └─* Round (Decoder)
                    └─* Tick (Arena)
                        └─* Instruction (Kernel)
```
